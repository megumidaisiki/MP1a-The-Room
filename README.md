# MP1a: The Room

A Unity3D VR homework project built with the XR Interaction Toolkit and OpenXR. The scene features an enclosed room with a planet-moon system, an orbiting comet with gravitational simulation, XR controller-driven interactions (quit, light color switch, camera teleport, comet spawning), and 16 decorated objects each with unique particle and spatial audio feedback.

## Contributors

- Yunfan Zhang

## Features

- Enclosed 15x15x15 room with custom wall materials, tiling, and a skybox
- VR player rig (OpenXR + XR Interaction Toolkit) with tracked headset and controllers
- Object-space parenting (Planet/Moon) and world-space UI canvas with controls text
- Shader Graph outline effect
- Controller-driven scripts: Quit, Light Switch, Camera Teleport, Decoration Feedback, Comet Spawner
- Comet spawner with double-integrator gravity simulation, arbitrary orbiting, and stable orbit launches
- 16 decoration objects, each with its own particle effect and spatial sound feedback
